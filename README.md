📊 Superhero Data Dashboard (HCI Mini Project)
โปรเจกต์ออกแบบ Interactive Dashboard สำหรับวิชา Human-Computer Interaction (HCI) โดยนำข้อมูลจาก Superhero/Manga มาวิเคราะห์และนำเสนอในรูปแบบที่เข้าใจง่าย

🚀 Key Features
Interactive Visualization: มีการใช้ UI Control (เช่น ปุ่มกดหรือตัวเลือก) เพื่อกรองข้อมูล และใช้ฟังก์ชัน Interval/Loop ในการแสดงผลกราฟแบบ Dynamic

Data-Driven: วิเคราะห์ข้อมูลจากไฟล์ superhero_data_analysis.csv

User-Centric Design: ออกแบบ Layout ให้ใช้งานง่าย พร้อมคำอธิบาย Concept การเลือกใช้สีและประเภทของกราฟตามหลัก HCI

🎨 Design Concept
Dashboard นี้ถูกออกแบบโดยเน้นความแตกต่างของสี (Color Contrast) เพื่อจำแนกประเภทข้อมูลอย่างชัดเจน การเลือกใช้กราฟเน้นความรวดเร็วในการกวาดสายตามอง (Scannability) เพื่อให้ผู้ใช้ได้รับข้อมูลที่ต้องการทันที โดยมีรายละเอียดแนวคิดการออกแบบอยู่ด้านล่างของหน้าเว็บ
